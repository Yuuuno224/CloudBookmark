## 五分钟上手（只想用，不想看代码）

1. **装扩展**：`npm install` → `npm run build` → 打开 `chrome://extensions/`
   → 打开"开发者模式" → "加载已解压的扩展程序" → 选项目里的 `dist` 目录。
2. **授权**：两种方式任选一种（设置页里都有图文步骤）
   - **方式一**：GitHub → Settings → Developer settings → Personal access tokens
     → **Tokens (classic)** → Generate new token → **只勾 `gist`** → 复制到设置页
   - **方式二**：建一个免费的 OAuth App（勾上 **Enable Device Flow**），
     把 Client ID 填进设置页，然后点「开始授权」+ 填一个 8 位短码。
     不用复制长字符串。
3. **同步**：在弹窗里点"立即同步"。第一次会在你的 GitHub 账号下自动创建一个
   私有 Gist，书签就存在那里。
4. **第二台设备**：装好扩展、用同样的方式授权、点一次"立即同步"即可。
5. **想要深色模式**：点右上角的太阳/月亮图标；想让它跟着系统走就去
   设置页 →「外观」。

## 名词速查

| 名词 | 一句话解释 |
|------|-----------|
| **扩展 / Extension** | 装在浏览器里的小程序。本项目就是一个 Chrome/Edge 扩展 |
| **Manifest V3** | Chrome 现在要求的扩展规范版本。最大的特点是"后台脚本会被随时回收" |
| **Service Worker** | 本项目的"后台"。没有界面，负责同步、监听书签变化。**会被浏览器休眠** |
| **Popup（弹窗）** | 点扩展图标弹出的那个小窗口 |
| **Options（设置页）** | 独立的全屏设置页面 |
| **Gist** | GitHub 提供的"存几个文本文件"的服务，可以理解成一个迷你仓库 |
| **IndexedDB** | 浏览器里的"小型数据库"，能存大量结构化数据 |
| **chrome.storage** | 浏览器提供的键值对存储，适合存很小的配置 |
| **快照 / Snapshot** | 某一刻全部书签的完整列表（本项目里就是一个数组） |
| **uid** | 我们给每一条书签起的"永久身份证号"，换电脑也不会变 |
| **base** | 上次同步完成时的样子。三方合并里的"第三份数据" |
| **三方合并** | 用"上次的样子 + 现在的本地 + 现在的云端"三份数据算出正确结果 |
| **冲突** | 两端改了同一处内容，机器猜不出该听谁的，需要你来决定 |
| **OAuth / 设备流程** | 一种"不用手动复制 Token"的授权方式：GitHub 给你一个 8 位短码，你填到网页上即可。详见 [01 文档第 7 节](01-架构总览.md) |
| **client_id / client_secret** | OAuth 应用的身份标识和密钥。client_id 是公开的，client_secret 必须保密——所以纯前端扩展只能用不需要 secret 的"设备流程" |
| **主题 / 深色模式** | 界面配色。全部颜色定义在 `src/ui/styles.css` 的两个变量块里，切换只是换 `<html>` 上的类名 |

## 目录结构一览

```
CloudBookmark/
├── src/
│   ├── core/        纯逻辑：数据类型、合并算法（不碰浏览器 API，可单元测试）
│   ├── platform/    浏览器 API 的包装：书签读写、存储、消息
│   ├── features/    具体功能：设置、Token、Gist、同步服务、历史记录
│   ├── background/  后台（Service Worker）的接线与消息路由
│   ├── ui/          界面：popup（小弹窗）+ options（独立设置页）
│   └── manifest.ts  扩展清单（权限、入口文件）
├── tests/           单元测试与"两台设备端到端同步"仿真
├── docs/            就是你现在看的这些
├── scripts/         辅助脚本（生成图标）
└── public/icons/    扩展图标（PNG）
```

想了解每一层的职责和一次同步的完整数据流，看 [01-架构总览](01-架构总览.md)。
